The resource file is unmodified. The runtime loader removes numeric dice indices
and uses the 7,776 words in source order. Optional capitalization/separators are
presentation transformations. Internal word hyphens are doubled when Hyphen is
the separator, preserving unambiguous word boundaries and generation entropy.
