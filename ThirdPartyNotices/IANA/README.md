# Offline network references

Retrieved 2026-10-22. IANA HTTP status codes, media types and IPv4/IPv6 special-purpose registry facts are bundled under the IANA/IETF CC0 policy: https://www.iana.org/help/licensing-terms (https://creativecommons.org/publicdomain/zero/1.0/legalcode).
RFC texts are not reproduced; references remain URLs. HTTP explanatory text in the app is original.

Common extension mappings are a curated subset of jshttp/mime-db 1.54.0, under MIT (license alongside). IANA registration-template additions are attributed in each mapping. Mappings are filename hints, not content identification or a security assertion. The app does not include the mime-db runtime or make network requests.

`MyApp/NetworkReferenceCore/Resources/reference-manifest.json` records source URLs, dates, counts and raw/generated SHA-256. `scripts/generate-network-references.py` accepts local downloads; it never downloads data or runs during builds. Update snapshots deliberately, including notices and resource tests.
